Automation

Comma-separated list of hostnames used to automatically unmute tabs with matching addresses. You can enter full or partial hostnames — if a match is detected, the tab will be unmuted automatically. This feature requires the "*://*/*" permission to access tab URLs.

Keyboard Shortcuts

[Google Chrome] Open extension shortcut settings page: chrome://extensions/shortcuts

[Mozilla Firefox] Follow these steps:

  1. Open about:addons
  2. Click the ⚙️ (gear icon)
  3. Select Manage Extension Shortcuts
